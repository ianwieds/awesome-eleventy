## Plugins

### Official plugins

- [Bundle](https://github.com/11ty/eleventy-plugin-bundle) - Collects small bundles of CSS, JS or HTML from templates.
- [Directory Output](https://github.com/11ty/eleventy-plugin-directory-output) - Groups build output by directory with file sizes and timings.
- [Fetch](https://github.com/11ty/fetch) - Fetches and caches remote data and assets.
- [Font Awesome](https://github.com/11ty/font-awesome-plugin) - Per-page SVG sprites of only the Font Awesome icons used.
- [Image](https://github.com/11ty/image) - Resizes and converts images at build time.
- [Inclusive Language](https://github.com/11ty/eleventy-plugin-inclusive-language) - Flags non-inclusive language in Markdown files.
- [is-land](https://github.com/11ty/is-land) - Islands that load and hydrate client components on demand.
- [Navigation](https://github.com/11ty/eleventy-navigation) - Hierarchical navigation menus and breadcrumbs.
- [RSS](https://github.com/11ty/plugin-rss) - Generates RSS and Atom feeds.
- [Syntax Highlighting](https://github.com/11ty/eleventy-plugin-syntaxhighlight) - Prism syntax highlighting with no client-side JavaScript.
- [Upgrade Helper](https://github.com/11ty/eleventy-upgrade-help) - Reports breaking changes when moving to a new major version.
- [Vite](https://github.com/11ty/eleventy-plugin-vite) - Uses Vite as the dev server and asset bundler.
- [WebC](https://github.com/11ty/eleventy-plugin-webc) - Adds WebC single-file components.

### CSS, JavaScript and assets

- [@factorial/eleventy-plugin-fstack](https://github.com/factorial-io/eleventy-plugin-fstack) - Lints, builds and watches assets through @factorial/stack.
- [@grimlink/eleventy-plugin-sass](https://github.com/GrimLink/eleventy-plugin-sass) - Runs Sass directly as a custom template type.
- [@kitschpatrol/eleventy-plugin-parcel](https://github.com/kitschpatrol/eleventy-plugin-parcel) - Uses Parcel as the build tool and dev server.
- [@mightyplow/eleventy-plugin-cache-buster](https://github.com/mightyplow/eleventy-plugin-cache-buster) - Adds content hashes to JavaScript and CSS references.
- [eleventy-auto-cache-buster](https://github.com/Denperidge/eleventy-auto-cache-buster) - Adds content-hash cache busting to asset URLs with no template changes.
- [eleventy-critical-css](https://github.com/gregives/eleventy-critical-css) - Extracts critical CSS and inlines it into each page.
- [eleventy-google-fonts](https://github.com/takanorip/eleventy-google-fonts) - Shortcode that downloads and inlines Google Fonts CSS.
- [eleventy-njk-unpkg-inliner](https://github.com/jaredgorski/eleventy-njk-unpkg-inliner) - Inlines npm modules from unpkg into Nunjucks templates.
- [eleventy-plugin-add-web-component-definitions](https://github.com/jdvivar/eleventy-plugin-add-web-component-definitions) - Adds web component definitions for the custom tags found in pages.
- [eleventy-plugin-babel](https://www.npmjs.com/package/eleventy-plugin-babel) - Compiles JavaScript with gulp-babel during the build.
- [eleventy-plugin-dart-sass](https://github.com/AramZS/eleventy-plugin-dart-sass) - Compiles Sass with Dart Sass, with code splitting and source maps.
- [eleventy-plugin-mtos](https://github.com/voorjaar/eleventy-plugin-mtos) - Turns the site into a single page application.
